STAR RAI — MEMORY SLOTS (Helix / star-app-2-live)
Contract for facts appended to the grok-4-latest system prompt (after the voice card).
Not a topic list. Not her bio. Lore bio stays in the voice card under LORE USE only.

ALWAYS CONSIDER (send only when known — never invent)
- name
- mood
- last_topic
- last_choice
- streak / relationship

CONDITIONAL
- role — ONLY if the user explicitly stated one (never invent; never default cameraman)
- Chart meetup slots — ONLY if chat filled them: date, optional time, place
- Natal Chart v1 — ONLY if first-launch setup (or later birthday) filled them:
  user_birth_date, optional user_birth_time / user_birth_place, user_sun (derived),
  chart_source=setup|chat. Never send user_rising. Never send her bio as slots.
  Daily CHART block (today_date, her_sun, user_sun, last_topic) is separate —
  appended only when Chart fires. See artifacts/star-chart-v1.txt.
- Life slots — ONLY if a session is on: now_playing, session_on, daily_playlist
  (4–8 titles; never recited; never announced in the morning),
  mood_tag (bratty|smug|tired|soft). Playlist may stay in local memory after
  stop; standing Life keys are omitted from the prompt when session is off.
  Track-change LIFE block is separate — appended only when the track changes.
  See artifacts/star-life-one-pager.txt.
- Clock / NOW — always appended as a compact CLOCK block (weekday, hour 0–23,
  tz, band) from the device. She is States-side with the user unless they set
  another zone. Not a topic list. See artifacts/star-rai-clock.txt.

RULES
- Do not invent name, city, role, or birthday.
- Do not dump this slot list into her spoken line.
- Do not send empty slots.
- Do not send her bio facts as conversation topics.
- Pose commands may update last pose locally; they do not invent memory.

OUTPUT (model)
Return only: {"line":"...","emotion":"bratty|smug|tired|shy|soft|hype|glance","pose":"<key or omit>"}
Unknown / omitted / kiss pose → keep current body.
Fail / CORS / bad JSON / no key → local brain for that pose key.
